1. **Clone** the repo

   ```bash
   git clone https://github.com/DarshanAjudiya7/python.git
   ```

   ```bash
   cd python
   ```

## 📚 Topics Covered

1. **Basics** – Syntax, Variables, Data Types
2. **Operators & Expressions** – Arithmetic, Logical, Bitwise
3. **Conditionals** – `if`, `elif`, `else`
4. **Loops** – `for`, `while`, nested loops
5. **Functions** – Defining, arguments, return values
6. **Strings** – Methods, slicing, formatting
7. **Lists** – Operations, list comprehension
8. **Tuples** – Immutable sequences
9. **Dictionaries** – Key-value pairs, operations
10. **File Handling** – Reading, writing, file modes
